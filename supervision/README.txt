Application de supervision du projet d'electronique de L3 EEA de Sorbonne Université.

src :       contient les fichier source processing 2.1.2 de l'application et des ses applets de
            simulation en plus d'un programme de test du langage.

test :      contient un test unitaire implémentant le spécification graphique de l'affichage
            (première itération avec l'ia gémini).

doc :       contient les fichiers .txt de travail pour l'élaboration des spécifications détaillées des
            différents aspects de l'application.

ressource : contient les prompts utilisé sur gemini et claude ainsi que les fichiers joints (image et
            texte) construit à partir des fichiers issus de doc.

bin :       contient le fichier de config de l'application lu au démarrage.
